Install it

You need a USB stick of at least 4 GB and a 64-bit PC.

  1. Download the latest ISO from the releases page.
  2. Write it to the USB stick with balenaEtcher, Rufus (DD mode) or Ventoy.
  3. Turn off Secure Boot in your BIOS settings, then boot from the USB stick.
  4. Pick Turkish or English in the boot menu and try everything live without installing.
  5. When you are ready, double-click Install ManifestOS on the desktop.
